# Editable figures and plotting data

The paper uses nine native TikZ/PGFPlots figures in
[`camera_ready_v3_10page/figures`](../camera_ready_v3_10page/figures).
Each `.tex` source produces a one-page vector PDF, 5.5 inches (396 PDF points)
wide. The shared fonts, colors, and plot styles are defined in
[`figure_style.tex`](../camera_ready_v3_10page/figures/figure_style.tex).
The bundled plotting CSVs are sufficient to rebuild all figures. Raw loan
records, a GPU, and an experiment rerun are not required.

## Build the nine paper figures

From the repository root, on Windows, macOS, or Linux:

```sh
python scripts/build.py --figures
```

The build requires Python and `pdflatex` on `PATH`, plus the LaTeX packages
`standalone`, TikZ/PGFPlots (compatibility level 1.18), `newtx`, `helvet`, and
`amsmath`. A complete TeX Live or MiKTeX installation supplies these packages.
The build compiles the nine selected sources and updates the PDFs beside them;
intermediate LaTeX files go in `camera_ready_v3_10page/figures/build/`.

The existing Windows wrapper is also available:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File camera_ready_v3_10page/figures/build_figures.ps1
```

For a single figure, change to `camera_ready_v3_10page`, create `figures/build`
if needed, and run:

```sh
pdflatex -interaction=nonstopmode -halt-on-error -file-line-error -output-directory=figures/build figures/fig02_learning.tex
```

Its output is `figures/build/fig02_learning.pdf`; copy it to
`figures/fig02_learning.pdf` to update the manuscript's included figure.
Compilation must run from the paper directory because the TeX sources use
`figures/...` paths. The build helpers set this working directory automatically.

All filenames below are relative to the figure directory. The first figure is

## Recreate plotting tables from bundled experiment results

From the repository root:

```sh
python camera_ready_v3_10page/figures/assessment_extract.py
python camera_ready_v3_10page/figures/revelation_extract.py
python camera_ready_v3_10page/figures/scripts/prepare_diagnostics.py
```

The assessment and diagnostics extractors use only Python's standard library.
The revelation extractor also requires NumPy and pandas. Their paths are
derived from the scripts' locations, so extraction does not depend on the
current working directory. These commands read the bundled result tables and
overwrite only derived figure CSVs, figure provenance JSON, and the generated
terminal table. They do not train models or run simulations.

The source inputs are:

- **Assessment and learning:** `experiments/results/finite_sample_summary.csv`
  and `real_data_evaluation/artifacts/tables/part_{a_certificates,b_masking_certificates}.csv`.
- **Diagnostics:** `experiments/results/experiment4_lower_bound_scaling.csv`
  and `experiments/results/experiment5_sensitivity.csv`.
- **Revelation and frontier:** the fixed-audit tables in
  `real_data_evaluation/artifacts/tables/`, the two `experiment6_*` frontier/cost
  tables in `experiments/results/`, and the completed sequential run in
  `camera_ready_v3_10page/revision_experiments/sequential_plugin/results/optimized/`.

The revelation extractor validates the completed-run manifest, source/output
hashes, all 1,080 mask/policy/round rows, matched unit-cost budgets, and stored
terminal comparisons before writing any output. Windows separators in archived
manifest entries are normalized for other operating systems. To validate the
bundled run without changing plotting files:

```sh
python camera_ready_v3_10page/figures/revelation_extract.py --check-only
```

`assessment_provenance.json` and `revelation_provenance.json` record input hashes,
filters, aggregations, and interpretation. Historical machine-specific paths
in released provenance are repository-relative; source and numerical-output
hashes preserve their recorded identities. Generated CSV byte formatting can
differ across Python/pandas versions or operating systems; compare numeric
values and column/row order when checking an independently regenerated file.

## Preview and verify

Install PyMuPDF for optional vector and preview checks, then run:

```sh
python camera_ready_v3_10page/figures/scripts/preview_and_check.py
python -m unittest discover -s camera_ready_v3_10page/figures -p "test_*.py"
```

The preview helper checks that each figure is one page, 396 PDF points wide,
has no text outside the page, and embeds no raster images. It writes color and
grayscale PNGs in `figures/previews/`, a four-page main-figure overview, and
`figures/final_qa.json`. Preview outputs are optional and are not inputs to the
paper. The ingestion regression tests use temporary synthetic fixtures and
never replace published experiment results.

The v1.0.0 public packaging check rebuilt all nine sources with MiKTeX `pdflatex`.
The rebuilt pages matched the archived paper figures pixel-for-pixel at
144 DPI, and passed the page-size, text-bound, and vector-only checks.
Assessment, learning, and diagnostic extraction reproduced all 27 associated
CSV files byte-for-byte. Revelation and frontier extraction reproduced all
30 associated CSVs and the terminal table byte-for-byte. The checked
environment used Python 3.12.4, NumPy 1.26.4, pandas 2.3.2, and PyMuPDF
1.27.2.2. All eight figure ingestion regression tests passed.

## Reading the plots

The learning fill is the difference between two saved mean widths; the
`n^(-1/2)` line is a visual guide normalized to 0.055 at `n = 1000`.
Coverage is descriptive over 20 shared masks, with three predictors per mask.
Sequential bands and frontier/cost bars are interquartile ranges across masks
or worlds, not confidence intervals. Fixed-audit percentages use the original
hidden pool, while sequential percentages use the initially hidden training
pool; both include integer batch rounding. Figure 1's surfaces and sleeve are
schematic geometry, with no probability encoded by area or volume.

In v1.0.3, the four secondary subtitles beneath panel headings in Figures 2 and 3 were removed. Panel titles, axes, vector plot geometry, figure dimensions, and all plotting CSVs are unchanged. Parameter settings and the issued-loan population remain specified in the manuscript captions.
